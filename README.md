# 🌱 像素花园 · PIXEL GARDEN

> 一个跑在终端里的迷你植物花园模拟经营游戏。种下去，浇点水，等一场雨，然后收获。

用 C11 写成，无第三方依赖，Windows / Linux / macOS 都能编译。全部界面是 ASCII + ANSI 彩色，宽度按中日韩字符的真实显示宽度对齐，不会错位。

## ✨ 玩法

一天一个回合。你有一块地、一点金币、水和肥料，要做的是：

1. **播种** —— 从背包里挑一颗种子种进空地块，种子要先在商店买。
2. **照料** —— 土壤的水分和养分每天被作物消耗，不够就掉健康；长虫了要花 12 金币除虫。
3. **等** —— 按 `7` 推进一天，看天气和随机事件怎么折腾你的园子。
4. **收获** —— 进度条到 100% 会亮 `★可收获`，卖掉换金币，再用金币买种子、买水肥、扩地。

节奏参考：胡萝卜 4 天、小麦 3 天、玫瑰 8 天。稳一点就先种小麦滚本金，熟了再上雏菊和玫瑰。

### 影响收成的因素

| 因素 | 效果 |
|---|---|
| 天气 | 晴 +10% 生长但更耗水；雨 +5% 且省一半水；暴风雨 −10%、额外掉血；多云无影响 |
| 当季作物 | 生长快 20%（胡萝卜/土豆秋天，小麦/仙人掌夏天，雏菊/玫瑰春天） |
| 冬季 | 所有作物生长 −15% |
| 虫害 | 生长减半，直到你除虫 |
| 健康 | 收获品质 = 50% + 健康/2，缺水缺肥掉健康，健康归零整株枯萎、地块清空 |
| 随机事件 | 集市开张（当天售价 +30%）、丰收日（生长 +25%）、夜露（全场地块水分 +15）、虫害爆发 |

| 植物 | 种子 | 成熟 | 售价 | 净利 | 解锁条件 | 当季 |

### 成就

`初收`（第一次收获）、`老农`（累计收获 10 次）、`富翁`（累计收入 1000）、`满园`（8 块地全种上）、`收藏家`（六种植物都种过）。

## 🎮 操作

| 键 | 动作 |
|---|---|
| `1` | 播种：先选地块，再选种子（只列背包里有的） |
| `2` | 浇水：消耗 6 水，土壤水分 +40 |
| `3` | 施肥：消耗 3 肥料，土壤养分 +35 |
| `4` | 除虫：12 金币，清除虫害并回 15 健康 |
| `5` | 收获：进度满 100% 才能收，按健康结算品质 |
| `6` | 商店：水 / 肥料 / 种子货架 / 扩建地块（150 金币，最多 8 块） |
| `7` | 推进一天 |
| `8` / `9` | 存档 / 读档（`garden_save.dat`） |
| `0` | 退出 |

输入只接受数字，输错了会提示范围并重新询问。存档读档失败（文件缺失、被截断、版本不符、数值越界）只会提示原因，不会破坏当前进度。

## 🔨 编译运行

### CMake（推荐，CLion 直接打开即可）

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/plant_retry
```

Windows + MinGW 也可以用 `MinGW Makefiles` 生成器：

```bat
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
build\plant_retry.exe
```

### 直接调编译器

```bash
gcc -std=c11 -O2 -Wall -Wextra -o plant_retry main.c pgsm.c ui.c save.c
```

### Makefile

```bash
make        # 或 mingw32-make
make run
make clean
```

> Windows 终端建议用 Windows Terminal 或新版控制台，老式 `cmd` 对 ANSI 颜色和 UTF-8 的支持不稳定。程序启动时会尝试把控制台切到 UTF-8 65001 并开启 VT 转义；如果开不了，会自动降级成无颜色输出，不会出现乱码方块。

## 📁 代码结构

| 文件 | 职责 |
|---|---|
| `pgsm.h` | 类型、常量、全局接口（`Plant` / `Plot` / `Player`） |
| `pgsm.c` | 游戏规则：种植、照料、生长、收获、商店、天气与事件、成就 |
| `ui.h` / `ui.c` | 界面层：彩色面板、进度条、CJK 宽度对齐、菜单与输入 |
| `save.c` | 文本存档的写入与校验读取 |
| `main.c` | 主循环与菜单分发 |
| `CMakeLists.txt` / `Makefile` | 构建脚本 |

界面和规则分开，`pgsm.c` 不直接 `printf`，全部通过 `ui_*` 输出；换皮肤只要改 `ui.c`。

## 🐛 与原版的差异

原版是单文件 + 全局变量的练手版本，这次重写修掉了这些问题：

| 原版问题 | 现在 |
|---|---|
| 土壤水分判断前先扣减，导致每天都判“缺水” | 先比较再扣减 |
| `100 / total_days` 整数除法，7 天的作物永远长不满 | 千分制生长值，按天累加，快慢由倍率决定 |
| 枯萎后不清理地块，`planted_days` 一直涨 | 枯死即清空地块，记录一并重置 |
| 作物卖价高得离谱（4 天 900 金币），经济几轮就崩 | 重做数值：净利 70~430，回本周期 3~8 天 |
| `get_plot` 用写死的常量，读档后地块数不对就崩 | 全程用 `player->plot_count`，读档时校验 4~8 |
| 存档直接 `fwrite` 结构体，换编译器就废 | 文本存档 + 版本号 + 逐字段范围校验 |
| `scanf` 读输入，输入字母就死循环 | `fgets` + `strtol`，非法输入重问不卡死 |
| 没有天气、事件、成就、扩地、除虫 | 全部补齐 |
| README 里躺着未解决的冲突标记 | 就是这份文档 |

## ⚠️ 已知限制

- 单存档位，存档写在程序当前目录；
- 没有音效和图形，纯终端；
- Windows 上如果控制台不支持 VT 转义，颜色会自动关掉（功能不受影响）；
- 存档格式为文本，手动改文件会被范围校验拦下来（这是有意为之）。
